# AgentMeter 0.12.0

2026 年 11 月 19 日。

- **多机同步**：设置菜单新增「多机同步（合并用量）…」。用 6 位短码在 5 分钟内配对两台设备；主密钥只在设备之间用 X25519 + HKDF 派生的密钥、ChaChaPoly 封装传递。同步服务只保存密文、临时公钥与槽位状态，读不到用量、额度或设置明文。
- **自动同步**：配对后可选择关闭 / 5 分钟 / 30 分钟 / 1 小时 / 1 天；面板显示上次同步时间与本次合并的本机、远端额度行数。
- **额度合并**：账户页新增「其他设备同步的额度」；同一账号按最近一次观测展示，不重复累加，不同账号分行。
- **边界**：同步数据走独立投影，不进快照、本机合并视图、覆盖矩阵与本机合计；本机数据仍以实时账本为准。

测试：Python 874 项、Swift 122 项、同步服务 45 项、桌宠运行时 28 项、7 个内置形象包严格校验全部通过；真机本机账本对账 3,366 项通过，0 失败、0 不可判定。

分发文件为 `AgentMeter-0.12.0-macos-arm64.dmg`。App 与 DMG 均使用 Developer ID Application 签名（Team WTTNX5S72B），已通过 Apple 公证并装订票据。见[安装说明](INSTALL.md)。
