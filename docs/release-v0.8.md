# v0.8.0 发布说明

2026-10-21 发布；App 内部版本为 0.8.0。适用于 macOS 14+、Apple Silicon（arm64）。

## 新增：用量报告与一键分享图

「本机消耗」页时间段筛选旁新增分享按钮，打开独立的**用量报告**窗口：

- **周期联动**：报告的时间段与本机消耗页共用同一个筛选（今日 / 7 天 / 30 天 / 全部），切换即时生效。
- **报告明细**：总览（Token 总量、请求数、缓存命中率、API 等价费用、活跃应用数）、Token 构成（新输入 / 输出 / 缓存读 / 缓存写）、按应用与按模型的 Top 排行，口径与本机消耗页逐位一致，只含本机消耗，不含账户余额。
- **四套风格分享卡**：极简、原生、极光、霓虹，横版宽幅，宽度固定、高度随内容自适应，PNG 按 2x 输出。
- **一键复制与保存**：复制图片直接进剪贴板，可粘贴到微信 / 飞书 / 小红书；保存 PNG 走系统保存面板。
- **口径标注**：图片页脚标注「数据来自本机账本 · 只读聚合 · 不含对话内容」「费用为 API 等价估算」，不泄露对话正文与凭据。
