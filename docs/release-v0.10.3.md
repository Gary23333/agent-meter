# AgentMeter 0.10.3

2026 年 11 月 10 日。本版新增 Qoder 每日活动积分的自动领取，其余功能与统计口径不变。

## Qoder 每日 100 积分（新）

- **来源**：Qoder CN 桌面客户端自己的登录态。活动接口在 `openapi.qoder.com.cn` 的 `/sash/api/v1/me/campaigns`（列表）与 `.../{id}/claim`（领取），只认桌面客户端的令牌，不接受网页 cookie。
- **规则**：官方每日北京时间 **10:00** 发布当日活动，每份 100 通用 Credits，领取后 30 天有效；错过的轮次不累计。
- **状态与领取**：账户卡新增「每日积分活动」行（待领个数 / 每份积分 / 每日刷新时刻 / 今日已领）。自动领取默认关闭；开启后到点自动领取，面板上的「领取」按钮可随时手动领一次。
- **幂等**：同一活动重复领取只回放既有发放，不重复到账。
- **凭据处理**：令牌从客户端的 `auth.v1.dat`（Chromium "v10" 信封）在内存中解密——用客户端自己的运行时完成，钥匙串密码经 stdin 传入、令牌经 stdout 取出，不落盘、不进日志；后端只把领取记录写进 `.runtime/rewards.json`（0600，不含任何凭据）。
- **首次会弹一次钥匙串授权框**（条目 `Qoder CN App Safe Storage`）：点「始终允许」后不再打扰。这是读取桌面客户端凭据的必要一步，与读取 Claude Code 登录态同属一类操作。

## 与既有版本的关系

v0.10.2 的桌宠系统、积分签到（TRAE / WorkBuddy）、用量集卡、本机消耗口径全部不变。「自动领取每日积分」开关现在覆盖三个平台：TRAE 签到、WorkBuddy 任务奖励、Qoder 每日活动。

## 验证

- Python 回归 663 项全过（含 Qoder 活动 23 项，含 node 端真实加解密往返与错误密码拒绝）；Swift 测试 74 项全过。
- 真机验收：只读列出当日活动、一次性真实领取（100 Credits，30 天有效期）、重复领取幂等回放、后端快照出现 qoder 行、账本无凭据。
- 本版 DMG 已经 Apple 公证（Developer ID，Team WTTNX5S72B）。

## 安装

从发布页下载 `AgentMeter-0.10.3-macos-arm64.dmg`，拖入「应用程序」覆盖旧版。要自动领 Qoder 积分，请在设置里打开「自动领取每日积分」；首次会请求钥匙串授权。
