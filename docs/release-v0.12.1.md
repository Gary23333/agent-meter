# AgentMeter 0.12.1

2026 年 11 月 19 日。

- 修复：应用刚启动、内置后端尚未监听（约 1 秒窗口）时点「立即同步」，会显示「无法连接本机后端 127.0.0.1:8769」并在页面上一直停留。现在同步前会等待后端完成启动（最多 15 秒）；后端确实不可用或启动失败时，提示为「本机后端尚未就绪，请稍后再试」。
- 其余功能与 0.12.0 相同。

测试：Swift 122 项、Python 874 项、同步服务 45 项、桌宠运行时 28 项与 7 个内置形象包严格校验通过；真机本机账本对账 3,366 项通过，0 失败、0 不可判定。

分发文件为 `AgentMeter-0.12.1-macos-arm64.dmg`。App 与 DMG 均使用 Developer ID Application 签名（Team WTTNX5S72B），已通过 Apple 公证并装订票据。见[安装说明](INSTALL.md)。
