# v0.9.8 发布说明

2026-11-01，macOS 14+，Apple Silicon。

## 会话活动（新页签）

- 菜单栏新增「会话活动」页签（账户额度之后第二位）：跨 harness 的最近会话/回合状态一览，进行中的任务一眼可见。
- **状态严格分级**：进行中（必须有阈值内的明确活动证据，默认 15 分钟）、疑似结束（超阈值无新事件，不宣称成功）、已完成 / 失败 / 取消（只接受明确状态事件）、未知（日志截断、状态不认识、覆盖不足；未知绝不等于失败）。
- **粒度如实标注**：每行带粒度徽章与局限说明——回合（ZCode，回合完成 ≠ 整个会话完成）、回合/步骤（DeepSeek Harness，`turn/end` 终态明确但不推断整个会话成败）、步骤（Kimi / Kimi 桌面端，子代理完成 ≠ 根任务完成）、生图调用（Codex 生图，调用状态明确但不代表整个 Codex 会话）、最近活动（Claude / Gemini / OpenCode，停止写入不能算成功、应用退出也不能算失败）。子代理会话单独标注。
- **回合时间线**：ZCode 与 dsh 的行可展开查看最近 5 个回合的起止、终态、模型、步数与 Token；回合终态汇总计数。
- **项目归属**：ZCode / dsh / Claude / OpenCode 显示真实项目目录的末段作为别名，可右键「命名项目…」重命名（仅存本机）；Kimi 显示 workspace 目录名；Gemini 项目哈希不可解，如实显示「未归属」。
- **Token 与估算费用**：行内显示 Token 总量与输入 / 输出拆分、缓存命中率；有价格表匹配的模型给出 API 等价估算费用（未计价模型留空，不当零）。

## 轻量端点与刷新节奏

- 新增本机端点 `GET /v1/activity`（schema 1）：只扫最近窗口（默认 24 小时），文件按 mtime 预过滤、增量解析，服务端 3 秒防抖；**调用它绝不会触发全量账户采集**。
- 刷新节奏三档：活动页可见 5 秒 → 后台存在进行中任务 15 秒 → 空闲 120 秒退避；独立于账户额度的 5 分钟快照轮询。
- 隐私边界与全后端一致：只读 usage、状态与路径元数据，绝不读取提示词、对话正文、工具输出与会话标题；仅监听 127.0.0.1，Bearer token 鉴权。

## 顺带改进

- CC Switch 导入日查询在同一轮采集内共享一次连接与一次查询（多直读来源并发时不再重复开库）；本机消耗合并树按快照缓存，菜单栏 20 秒时钟不再触发重算。
