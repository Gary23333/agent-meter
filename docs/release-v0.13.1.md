# AgentMeter 0.13.1

2026 年 11 月 24 日。

- **两台设备合并展示**：其他设备同步的额度与账户信息直接并入本机快照，账户页、顶部圆环、菜单栏与滚动条读同一份合并数据，看起来像一台机器在读取。
- 同一账户只有一张卡，每个额度窗口取两台中较新的读数；本机读不到的套餐、余额、重置卡、续费与积分更新日期由另一台补上，本机已有的不被覆盖。
- 只在另一台登录的账户移出「未接入」，作为普通账户卡片排序显示；另一台超过 1 小时未同步时，卡片与本机过期读取一样显示「采样于」。
- 账户页不再显示「来自某设备」「含其他设备同步的额度」与同步设备摘要；Windows 的其他设备额度卡片也不再标注来源。
- 低额度通知仍只针对本机读取的账户，避免两台设备对同一账户重复提醒。

测试：Python 1101 项（跳过 1 项）、Swift 143 项通过。Windows 端由 CI 编译验证。两台真实设备之间的合并展示尚未实测。

分发文件为 `AgentMeter-0.13.1-macos-arm64.dmg`。App 与 DMG 均使用 Developer ID Application 签名（Team WTTNX5S72B），并提交 Apple 公证、装订票据。见[安装说明](INSTALL.md)。
