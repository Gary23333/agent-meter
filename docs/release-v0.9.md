# v0.9.0 发布说明

2026-10-24 发布；App 内部版本为 0.9.0。适用于 macOS 14+、Apple Silicon（arm64）。

## 模型目录与计费绑定

- 新增公开 `models.dev` 模型目录同步：保存主流供应商的模型 ID、显示名、发布日期及输入、输出、缓存读取、缓存写入的每百万 Token 刊例价。
- App 启动后自动同步，之后每 6 小时检查；目录按 24 小时节流，也可在「模型与计费」窗口手动刷新。同步失败保留最近成功目录。
- 内置价格、同步目录和用户价格分层合并，用户修改优先；无有效价格的超前体验模型不会被自动视为免费。
- 新增体验模型 / 内部代号绑定：可沿用任一现有模型的四项 Token 单价进行 API 等价估算，绑定目标会标记在估算结果中。
- 补充 GPT-6.1 Sol、Claude Sonnet / Haiku 5.5、Kimi K3.1 / K2.7 等模型价格，并完善缓存写入价格。

## 七套主题与分享卡

- 新增「瓷白」浅浮雕、「钛影」深色金属机械、「棱镜」全息晶体三套立体主题，与极简、原生、极光、霓虹组成七套风格。
- 立体背景、卡片、图表、Tibo 与重置器均按主题适配；竖版用量分享卡同步支持全部七套风格。
- 报告窗口主题选择器与 README 演示截图更新为七套风格。

## 重置器体验

- 新增 24 / 48 小时观察窗切换与立即刷新。
- 优化机身纵深、屏幕内阴影、旋钮高光、数字过渡及无障碍摘要。
- 「各站口径」默认折叠；已验证记录默认展示 3 条，可展开查看更多。

## 验证

- Python 3.14 全量 284 项单元测试通过。
- Swift release 构建、ad-hoc 签名及 DMG 打包。
- 七主题各页面与七张竖版分享卡已离屏渲染检查。
- 真实公开目录同步验证通过：189 个有明确价格的模型可写入并重新加载；验证使用临时目录，不修改用户价格配置。

当前 DMG 使用 ad-hoc 签名，未做 Apple 公证；首次打开的处理方式见 `docs/INSTALL.md`。
