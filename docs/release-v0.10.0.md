# AgentMeter 0.10.0

2026 年 11 月 9 日。本版补齐三类历史账本、ZCode 桌面端重置卡、即梦画布 CLI 路由、签名与钥匙串加固，以及预算提醒、项目归因、周报环比、数据状态与省资源四项新功能。

## 新增本机账本

- **MiMo Code**：直读 `~/.local/share/mimocode/mimocode.db`（868 条 / 2.26 亿 token，2026-09-22 后停写）。独立来源，只进「本机消耗」。
- **DevECo**：同一解析路径读取 `deveco-stable.db`（4 条历史记录），随用量增长自动计入。
- **Kimi 旧 CLI**：补齐 2026-02→06 迁移前的 80 个会话文件（3,971 轮 / 3.96 亿 token）。旧格式无模型字段，一律按未知列名、不估价。
- 三者均与既有账本零重叠；verify 独立重算。本次安装版（真机）verify 3,185 项通过、0 失败。

## ZCode 与即梦

- **ZCode 重置卡**：读取 ZCode 桌面端自己的登录（AES 信封经 node 内存解密，凭据不落盘），查询重置卡状态并保留全部卡片、逐卡到期时间；本机实测 3 张周卡可用、最近到期 2026-12-22。无网页会话时该路线也可独立提供额度。
- **即梦 CLI**：`dreamina` 不存在时回退 `dreamina-canvas auth account`（身份与 VIP）；画布 CLI 不提供积分查询，积分仍由网页采集补齐。

## 新功能

- **预算与异常提醒**：设置日/周预算（人民币、API 等价估算口径）与异常倍率；超支或消耗速度异常时发通知，定位主要应用/模型；同一事件只提醒一次，补记不重复弹。
- **项目归因**：「项目」页按工作目录汇总 ZCode/OpenCode/MiMo Code/DevECo/DeepSeek Harness 的用量与费用；其他账本进「未归属」，不做推测；支持本机别名。
- **周报环比**：本机消耗页新增自然周/自然月对比（当期 vs 上一完整周期），含费用、缓存命中率与变动主要模型；按日汇总基准价估算并明示口径。
- **数据状态与省资源**：设置菜单新增数据状态窗口（来源状态、过期、未计价模型、快照时间）；省资源模式把刷新间隔变为 3 倍并可跳过指定高开销账本。

## 安全与稳定性

- **签名**：开发/分发构建找不到证书时明确失败，不再静默回退 ad-hoc（避免身份变化导致钥匙串反复弹窗）。
- **钥匙串**：保存改为就地更新（保留既有授权），启动只读启用来源且优先无交互；需要授权的槽位留给主动连接操作。
- **Qoder 版本漂移监测**：`scripts/recheck-qoder-usage.py` 在版本升级后抽样检查 token 字段（0.5.6 仍全为 0，只记积分，维持不臆造）。
- **Qoder 账户路由回退**：网页登录失效时自动回退本机 Qoder SDK 路线，过期会话不再挡死本地登录（两条路线都失效时仍提示重新登录）。

## 安装

从发布页下载 `AgentMeter-0.10.0-macos-arm64.dmg`，拖入「应用程序」。本版 App 使用 Developer ID 签名；公证状态以发布附件为准。
