# v0.6.0 发布说明

2026-10-15 发布；App 内部版本为 0.6.0。适用于 macOS 14+、Apple Silicon（arm64）。

## 新增：重置预测标签页（Tibo 全员重置）

面板新增独立的「重置预测」标签页，回答「ChatGPT / Codex 下一次全员重置大概什么时候」。

- **来源**：只读抓取三家第三方追踪站——Will Codex Reset（willreset.com）、Tibo Radar（codex-reset.com）、Codex Reset Monitor（codexreset.org）。纯公开 GET，不带 Cookie，也不发送任何本机数据。每 45 分钟抓一次，有源失败时 5 分钟后重试；最近一次成功结果会缓存，全部失败时按「过期」显示，不会当成零。
- **合成口径**：只用各站**自己公布**的 24 / 48 小时答复，给出区间 + 加权中位，并标出「接近 / 分歧」；站内未公布的模型字段只作为元数据列出，不参与合成。权重全部来自各站自报的质量（信心、Brier / 回测、样本量、新鲜度），超过 48 小时未更新的来源整体剔除。
- **承诺与倒计时**：站内挂着的「已承诺会再重置」单独成卡；没有可机读时间时显示「未给时间」，不编造倒计时。常见公告时段按北京时间显示倒计时。
- **历史记录**：多站记录的同一事件按帖子去重合并，并标出几家印证。
- **通知**：只在**已公告**的时段开始 / 结束，或追踪站记录到落地时提醒；概率高低永远不会触发通知。
- **边界**：不写入任何账户的重置时间，不进账户卡片、菜单栏行情条或本机消耗；设置菜单「全员重置预测（联网读第三方追踪站）」可随时关闭。
- 这是第三方独立统计，与 OpenAI 无关；官方从未保证未来会重置。

## 新增：Q 版 Tibo 与重置器

预测页顶部是「Tibo 重置器」卡片：

- **Q 版 Tibo** 会随数据换表情：犯困（48 小时中位低于 20%）、等待、手按按钮（站内挂着承诺，或 48 小时中位 ≥ 50%）、拍下按钮（已公告时段进行中）、星星眼庆祝（追踪站 24 小时内记录到一次高 / 中信心的落地，与通知同一判定）。气泡只复述页面上已有的数据。
- **重置器**：圆顶按钮、闪烁的天线灯、旋钮，屏幕显示 48 小时中位、24 小时值和 10 段 LED 进度条，出票口打印下一个已知时段的倒计时。
- **四套主题各有造型**：极简为黑白线稿、原生用 macOS 系统色、极光是粉彩渐变与微光、霓虹是发光线框；整页原先写死的颜色都改为跟随主题。
- 动画很轻（眨眼与轻微浮动），只在标签页打开时运行，开启「减少动态效果」时停止。
