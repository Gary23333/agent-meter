# AgentMeter 0.9.9

2026 年 11 月 4 日发布，适用于 macOS 14 及以上的 Apple 芯片 Mac。

- **按应用查看用量和会话。** 在菜单栏的「应用」页展开卡片，即可查看今日与累计 Token、本机直读、迁移历史、可采集字段和最近 24 小时的会话。Codex 普通会话与内置生图活动归入同一张卡片。Agent Launcher 已从应用发现清单中移除。
- **本机采集独立运行。** 后端直接读取各应用的本机日志和数据库，纯本地模式也能统计用量。已有的历史导入文件继续单独列账。升级后仅有旧 CC Switch 数据库的记录不会自动进入新账本。
- **改进 Token 与费用核算。** Codex 支持压缩日志、分支与续接会话，源数据只有总量时保留为未分类。模型估价按应用和请求时间计算，账户额度与本机用量分别更新。

从发布附件下载 `AgentMeter-0.9.9-macos-arm64.dmg`，将「Agent 用量.app」拖到「应用程序」。App 和 DMG 均已使用 Developer ID Application 签名并通过 Apple 公证。可将同页的 `SHA256SUMS` 下载至 DMG 所在目录，运行 `shasum -a 256 -c SHA256SUMS` 核对文件。
