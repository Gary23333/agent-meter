# v0.4.1 发布说明

2026-10-09 发布；App 内部版本为 0.4.1。适用于 macOS 14+、Apple Silicon（arm64）。

本版是品牌更新，不改动采集后端与数据口径：

- **新 Logo**：两圈 270° 仪表（外圈 5 小时窗口、内圈 7 天窗口）环绕 Agent 星芒，主色取自极光主题的蓝紫渐变。SVG 源文件位于 `docs/images/logo/`（应用图标、单色标志、横版组合）。
- **App 图标**：应用包新增 `AppIcon.icns`，Finder、DMG 与「应用程序」中不再显示通用图标。
- **面板标志**：面板顶部的标志由系统仪表符号换成新 Logo，并按主题配色——原生用系统强调色底板，极光用渐变圆角底板，霓虹保留六边形外框、圆环改为品红/青色；极简主题仍不显示标志。

安装方式与之前相同（见 [INSTALL](INSTALL.md)）。二进制见 GitHub Release `v0.4.1`。
