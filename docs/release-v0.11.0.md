# AgentMeter 0.11.0

2026 年 11 月 12 日。

- 桌宠新增「麻薯」。分享图可带上桌宠，支持昨日用量气泡、可选漫游、拖入安装形象包，以及点击会话标签打开对应应用。修正「失联」「睡觉」「没力气」动画的双影。重置卡明细缺失时，桌宠仍能更新实时状态。
- Claude 支持复用桌面登录态读取额度，卡片同时显示已用和剩余比例，重置时间按官网显示精度取整。TRAE 每日签到会补带本机设备 ID，附加奖励展示状态。MiniMax Design 账户卡显示本机媒体任务的积分估算。
- 重置预测支持手动录入公告和记录实际重置与预测的偏差。
- 报告页可导出缓存中的 JSON 或 CSV 历史。模型价格表更新，跨币种换算使用联网 USD/CNY 报价。断网时沿用上次报价，首次无缓存时标示离线参考汇率。

Python 835 项、Swift 91 项、桌宠运行时 28 项测试通过。开发窗口 10 项交互自检及 Claude 桌面登录态实测通过。实际汇率下，本机账本 3,301 项对账通过。见[批次验收](local-upgrade-batch-plan-2026-11-12.md)。
