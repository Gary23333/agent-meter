# AgentMeter 0.12.3

2026 年 11 月 20 日。

- **消耗页合并全部设备**：`/v1/sync/history` 新增 `usage` 投影，只汇总其他设备的行，本机仍以实时快照为准；Token、请求数与费用在本机数据上叠加，不重复计算。费用使用本机价格表按谷时基价估算，模型不在表内时费用为下界，页脚会列出。
- **额度归属修复**：同步额度按后端相同的账户键规则匹配（显式 `account_key`，否则回落来源 id）；Antigravity 等隐式账户的远端额度直接进入自己的账户卡片，并注明「含其他设备同步的额度」。
- 消耗页签名称从「本机消耗」改为「消耗」；页头显示「全部设备 · 含 N 台其他设备」或「仅本机」。报告与分享图仍保持本机口径。
- **同步地址内置**：应用固定使用 `https://sync.joycine.xyz`，配对页不再要求填写服务器地址。
- **远端额度状态可见**：`/v1/sync/history` 新增 `remote_quota` 投影；本机观测更新时仍显示本机值，但卡片会标注「其他设备也上报了 N 条额度」，远端更新时标注「含其他设备同步的额度」。
- 远端额度条补上模型分组（Gemini / 3P）与重置倒计时；消耗页底部的周/月环比卡在本机口径时明确标注「本机」。

测试：Python 897 项、Swift 128 项、同步服务 45 项、桌宠运行时 28 项与 7 个内置形象包严格校验通过；真机本机账本对账沿用 3,366 项 0 失败的基线。

分发文件为 `AgentMeter-0.12.3-macos-arm64.dmg`。App 与 DMG 均使用 Developer ID Application 签名（Team WTTNX5S72B），已通过 Apple 公证并装订票据。见[安装说明](INSTALL.md)。
