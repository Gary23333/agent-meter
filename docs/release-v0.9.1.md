# v0.9.1 发布说明

2026-10-24 发布；App 内部版本为 0.9.1。适用于 macOS 14+、Apple Silicon（arm64）。

## 七套主题视觉升级

- 为极简、原生、瓷白、极光、钛影、霓虹、棱镜建立统一的三级文字、卡片底色、选中态、间距与圆角规范，同时保留各主题原有个性。
- 提升深色主题的小字与辅助信息对比度；瓷白固定完整浅色外观，钛影选中态改用深色文字。
- 收敛霓虹与棱镜的辉光、彩虹描边和背景装饰，让颜色更多服务于图表与状态表达。

## 重置器与数据页面

- 重置器的 24 / 48 小时观察窗、概率区间、中位数、来源和记录日期统一对齐，历史日期不再折行。
- 账户额度、应用覆盖、本机消耗及模型排行重新梳理信息层级；应用名、指标和数值采用稳定列宽与等宽数字。
- 优化 Tibo 气泡、机器小字与图标在不同主题上的可读性。

## 分享卡与报告窗口

- 七套竖版分享卡同步升级主数字、辅助文字、构成图例、应用与模型排行、页脚和分隔线。
- 报告窗口明细与主面板使用一致的对齐及排版规范，费用和 Token 列更易扫描比较。
- README 演示截图与七主题对比图已更新为本版本界面。

## 验证

- Python 3.14 全量 284 项单元测试通过。
- Swift release 构建、ad-hoc 签名及 DMG 打包。
- 七主题四个主页面在浅色 / 深色外观下的 56 张渲染图、7 张竖版分享卡、报告窗口及补充界面均已检查。

当前 DMG 使用 ad-hoc 签名，未做 Apple 公证；首次打开的处理方式见 `docs/INSTALL.md`。
