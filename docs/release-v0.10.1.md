# AgentMeter 0.10.1

2026 年 11 月 10 日。本版首次把 2026-11-08 接入批次（原定 v0.10.0，未发布）与桌宠系统一起交付，并把「项目」页并入「应用」页。v0.10.0 从未公开发行，本版为其全部内容再加三项新增。

## 桌宠系统（新增）

- 常驻桌面的透明置顶宠物窗口：不抢焦点、可拖拽、可点击穿透、位置记忆，尊重「减弱动态效果」。
- 状态大脑（`GET /v1/pet`）：把额度、会话活动、重置预测与外部事件仲裁成宠物状态；未知额度显示困惑而不是躺平，停止写入不算成功，全程只读、不触发全量采集。
- 六个内置形象：`gauge` `blob` `bot` `cat` `tibo`（three.js 程序化）与 `bit`（像素精灵图）；形象包规范 `agentmeter-pet/1` 支持本地第三方形象，不联网下载。
- 功能：额度守卫 HUD、会话看板、专注计时、久坐提醒、右键快捷操作、可用桌宠气泡代替系统通知。
- 两套「做形象」skill（three.js 前端、生图模型）与校验/预览工具，见 `.claude/skills/`。
- 设置菜单新增「桌宠」分组；Agent 钩子可经 `agent_meter pet emit / focus` 联动。

## 界面

- 「项目」tab 并入「应用」tab：项目归因变成应用页底部的可折叠区块，默认收起、显示「已归因 / 总计」摘要，展开偏好会被记住；旧 tab 选择自动迁移。tab 栏现为 账户额度 / 应用 / 重置预测 / 本机消耗 / 桌宠 五项。

## 接入批次（原 v0.10.0 内容）

- **新增本机账本**：MiMo Code（868 条 / 2.26 亿 token）、DevECo、Kimi 旧 CLI（3,971 轮 / 3.96 亿 token，2026-02→06 缺口补齐），与既有账本零重叠。
- **ZCode 重置卡**：读 ZCode 桌面端自己的登录（AES 信封经 node 内存解密，凭据不落盘），本机 3 张周卡、最近到期 2026-12-22。
- **即梦 CLI**：`dreamina` 不存在时回退 `dreamina-canvas auth account`。
- **预算与异常提醒**、**项目归因**、**周报环比**、**数据状态与省资源模式**四项新功能（详见 [v0.10.0 说明](release-v0.10.0.md)）。
- **签名与钥匙串加固**：dev/dist 找不到证书明确失败；钥匙串就地更新；启动只读启用来源且无交互。
- **Qoder**：版本漂移监测（0.5.6 仍只记积分）；网页登录失效自动回退本机 SDK 路线。

## 安装

从发布页下载 `AgentMeter-0.10.1-macos-arm64.dmg`，拖入「应用程序」覆盖旧版。若菜单栏「连接网页账户」里 qoder / workbuddy / mimo 显示登录过期，重新登录即可（验收入口 `scripts/check-account-connections.py`）。
