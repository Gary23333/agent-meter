# AgentMeter 0.13.0

2026 年 11 月 24 日。

- **全部额度互相同步**：同步额度此前要求每条带 `window` 字段，只有 Codex 满足，其余来源被静默丢弃。现在窗口名依次取自窗口名、窗口时长或 `window_minutes`，都没有时视为该额度唯一的窗口；Mac 与后端使用同一规则，本机额度条与同步过来的同一窗口合并为一条，取最新观测。
- **无标识账号去重**：Kimi、WorkBuddy、MiniMax Code、ZCode 与 Windows 上传的账户没有账号标识。两台设备上的同服务账户在重置时间相差不超过 10 分钟、用量走势符合同一账号时合并；否则各自成卡（0.13.1 起不再标注来源设备）。两个不同的账号标识永不合并；同一设备同一服务登录多个无标识账号时，该服务的额度不上传。
- **Windows 同步修复**：此前「立即同步」上传的是未转换的采集结果，同步包为空；现已修复。ZCode、WorkBuddy 等需要密钥的账户额度取自最近一次刷新的结果上传，密钥不离开本机。账户页新增仅其他设备可见的额度卡片。
- **读取修复**：系统 Python 自带的新版 SQLite 无法以只读方式打开没有日志文件的 WAL 数据库，MCode、OpenCode、豆包等 6 个本地来源可能读取失败；现对这类数据库使用不可变只读方式打开。
- **真 3D 视觉**：已获得奖章与 Tibo 重置器使用 SceneKit 实时光照渲染，静止时缓存为图片不占 GPU；简约主题保持平面。全部字号统一为整数点，金额列不再折行；预算窗口布局收紧。

测试：Python 1101 项（跳过 1 项）、Swift 137 项通过。Windows 端的 C# 改动由 CI 编译验证。两台真实设备之间的互通尚未实测。

分发文件为 `AgentMeter-0.13.0-macos-arm64.dmg`。App 与 DMG 均使用 Developer ID Application 签名（Team WTTNX5S72B），并提交 Apple 公证、装订票据。见[安装说明](INSTALL.md)。
