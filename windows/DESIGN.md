# Windows 托盘弹层设计

Windows 版以右下角通知区域为入口，默认界面是随用随收的弹层。视觉参照上游的品牌标记、额度环、胶囊导航和服务色卡片，交互遵循 Windows 托盘使用方式。

## 弹出与收起

- 默认面板约为 440 × 680，靠触发位置所在屏幕的任务栏边缘打开，尺寸受工作区限制。不显示系统标题栏，不占据任务栏窗口按钮。
- 左键托盘图标切换显示；点击面板外部或按 Esc 收起。固定按钮可以保持面板展开，Esc 仍可收起；固定状态只在当前进程生效。
- 顶部提供刷新、固定和更多设置。更多设置复用托盘右键菜单，避免用户来回寻找两个不同的设置入口。
- 打开设置菜单、账户窗口或保存对话框时，面板应保持存在。一次托盘点击引起的失焦不能导致面板立即重新打开。
- `--window` 保留普通窗口模式，供调试、辅助操作和需要任务栏入口的用户使用。

## 信息层级

账户页保留双周期额度环，下方直接进入账户卡片。其他页面收起额度环，为应用列表、报告和预测腾出空间。页面切换回到顶部，页内筛选或展开尽量保留位置。

页面导航是一条连续胶囊，选中项使用主题强调色。滚动区使用细轨道；底层仍由 Windows 窗体管理内容滚动，保留滚轮、拖动、Page Up / Page Down、Home / End。账户来源使用语义图形与服务色，同时提供完整文字名称。

账户倒计时只读取服务返回的重置时间，页面可见时按分钟更新。到了时间会提示待刷新，不自行改写剩余额度。第三方预测位于独立页面，不能进入账户倒计时或替代账户状态。

## 重置预测

综合预测复用上游的加权中位数规则，按站点自报的信心、校准情况、样本和新鲜度计算；不是经过本项目独立校准的概率。超过 48 小时的来源不参与合并。色带表示站点数值的最小值和最大值，不能解读成置信区间。

时间窗口必须来自明确的机器可读时间。常见公告时段是统计规律，站点转述的时间仍需验证是否兑现；文字承诺不生成倒计时。时间到了只显示待确认。历史事件区分公告时间与站点记录的生效时间，确认标签也只是站点的标注。

联网和缓存仍由用户主动开启的预测功能负责；界面上的秒级倒计时不会增加网络请求。投影只保留固定来源名称、时间、数字和事件分类，不直接显示第三方页面的自由文本、脚本或链接。

## 实现与验证

Windows 11 通过 [DWM 圆角接口](https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/ui/apply-rounded-corners) 请求系统圆角；较旧的 Windows 使用窗口区域裁剪。阴影、圆角和高 DPI 的最终效果仍需实体设备验收。弹层失焦使用 [Form.Deactivate](https://learn.microsoft.com/en-us/dotnet/api/system.windows.forms.form.deactivate) 并检查菜单、拥有的子窗口和模态状态。

构建机使用纯演示数据生成深浅主题、窄窗口及滚动截图；交互检查覆盖固定、菜单、子窗口、失焦和 Esc。它验证程序路径，不替代真实任务栏、隐藏图标、多屏或多 DPI 设备的完整验收。
