# Windows 更新记录

## 0.1.0-alpha.17 · 2026-11-15

- 用量报告增加已结束自然日的同长度对照：本期与上期取相同的完整天数，当前日期不计入；月天数不同时截到共同长度。
- 上期为零时不计算增幅，首日没有完整可比日期时不显示比较；部分账本不完整时继续标注。
- Markdown 报告同步加入对照口径，PNG 分享图仍显示自然周期总量；两者均不包含账户或会话内容。

## 0.1.0-alpha.16 · 2026-11-15

- 本机消耗页加入与原版对应的今日、7 天、30 天和累计周期切换，汇总、账本用量、积分及可计算的 API 等价费用随周期更新；选择保存在本机。
- 各周期费用分别计算，缺少模型价格、完整分组或峰谷信息时标注不完整；未知费用不当作零。趋势和模型排行仍明确标注各自周期。
- 调整图表和图例背景，使其融入深浅主题的卡片；辅助功能描述随周期变化。
- 新增周期切换、偏好恢复和多周期费用测试；隔离构建机以虚构数据渲染窄屏页面。

## 0.1.0-alpha.15 · 2026-11-15

- 在本机消耗页加入 JSON / CSV 结构化汇总导出，支持按来源和周期查看 Token 拆分；CSV 兼容 Windows Excel 的中文编码。
- 导出只包含固定来源名、周期、状态和汇总数字；未知字段保留为空或 null，真实零值保留为零，不导出账户、项目路径或会话内容。
- 增加演示数据标记和隐私过滤检查；不同账本可能重叠，不能把导出结果当作账户账单。真实保存对话框仍需设备验收。

## 0.1.0-alpha.14 · 2026-11-15

这一版把账户信息收进统一卡片，并让托盘本身显示可用余量。

- 托盘加入百分比数字和分级颜色，可选择固定来源、自动最低余量或仅显示品牌；提示保留精确数值、来源和周期，不展示账户别名。
- 图标按分钟检查时效，过期、关闭或未知数据回退为应用图标；不新增账户请求。
- Codex 积分与重置卡、Kimi 钱包、WorkBuddy 积分和套餐、DeepSeek 分币种余额统一到对应账户卡片；Claude 有套餐信息时显示在标题下。
- 重置卡支持到期排序、展开和收起、兑换状态与明细缺失提示；过期仅提示待刷新，不改写账户总数。
- 修复部分服务返回小数时间戳时，额度环与重置卡可能遗漏时间的问题。
- 将细滚动轨道与内容裁剪区域分开，避免长卡片重绘时覆盖滑块；补充拖动检查。
- 新增账户明细边界、托盘来源、失效规则、原生图标生命周期和深浅色预览检查。真实新增账户与多 DPI 任务栏仍需继续验收。

## 0.1.0-alpha.13 · 2026-11-15

这次主要重做托盘弹层，集中改善普通窗口感过重、页面空间利用不足和预测功能不完整的问题。

- 默认使用约 440 × 680 的无边框弹层，隐藏任务栏窗口按钮；点击外部、Esc 或托盘图标可收起，支持临时固定。
- 顶部加入品牌标记、刷新、固定和更多菜单；设置菜单跟随主题，账户和外观入口与托盘右键一致。
- 六个页面共用胶囊导航；账户页保留额度环，其他页面采用紧凑头部。卡片圆角、服务图形和细滚动轨道一并调整。
- 账户页增加按分钟更新的周期倒计时；到了时间只提示待刷新，不自行改变账户额度。
- 预测页加入上游加权中位数、站点范围、明确时间窗口、来源对照和可展开的历史事件。时间到点不等于确认重置。
- 历史随预测缓存周期读取，修复后续刷新可能遗漏历史的路径；未知值仍保持缺失。
- 新增弹层交互、键盘翻页、预测时钟边界、合并规则与历史字段过滤检查；新版截图全部使用虚构演示数据。

仍是早期移植版，未完整复现 macOS 版的所有数据源、材质、动效和桌宠。真实任务栏、多屏、高 DPI 及第三方真实账户仍需继续验收。

## 0.1.0-alpha.12

- 应用页可见时单独刷新本机活动，切换页面或隐藏面板会取消读取。
- 活动刷新与完整刷新互斥；失败时保留上一次记录，不调用账户接口。

## 0.1.0-alpha.11

- 新增按工具汇总的应用概览、近期更新筛选和数据覆盖展开。
- 区分账户额度、本机 Token 与活动记录，避免把历史更新时间理解为应用正在运行。

## 0.1.0-alpha.10

- 在支持的账户卡片中展示本机汇总与近 30 个自然日的趋势。
- 明确本机记录未按账户划分；MiniMax 多账户不重复归入同一份账本。
