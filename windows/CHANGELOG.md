# Windows 更新记录

## 未发布

- 托盘增加「每日积分领取」：默认关闭，可在设定时刻自动执行 TRAE 签到与 WorkBuddy 已完成任务，也可手动领取；只用应用内登录资料，失败不重试，Qoder 标记为暂不支持。
- 用量报告增加已结束自然日的同长度对照，与 macOS 共用 `comparable_days` 字段；当天不计入，上期较短时截到共同天数。
- 托盘增加「多机同步」：创建空间、6 位短码配对、SAS 对照、设备列表、立即同步、移除设备和断开本机；与 macOS 共用 X25519/HKDF-SHA256/ChaCha20-Poly1305 协议，主密钥存 Windows 凭据管理器，只上传聚合字段。
- 新增同步加密、远端客户端和 Windows 编排层；固定向量、真实本地 `sync_server` 双设备端到端和打包后端创建空间／push 已验证，真实 Mac↔Windows 双机联调与窗口交互仍待验收。
