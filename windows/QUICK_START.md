# Agent Meter for Windows 快速使用

1. 解压后保留完整文件夹，运行 `AgentMeter.Windows.exe`。
2. 在 Windows 通知区域找到 Agent Meter 图标；如果没有看到，可展开隐藏图标。
3. 左键显示或隐藏无边框面板，点击外部或按 Esc 可收起；账户额度超过四个时可用额度环两侧箭头切换；顶部图钉可固定展开，三个圆点打开更多设置，与托盘右键菜单一致。可在「账户查询」中分别调整读取；账户与本机账本默认每 15 分钟刷新，也可在「刷新间隔」选 5 或 30 分钟。更频繁刷新会增加已启用账户的查询次数。MiniMax、DeepSeek、WorkBuddy、智谱、火山方舟、MiMo 和 Qoder 查询默认关闭；开关只影响账户查询，不影响本机历史。
4. 右键菜单「界面风格」可选择七种配色；当前 Windows 版的材质和动效仍在完善。
5. 右键菜单「自定义模型价格」可覆盖内置美元价格，单位是每百万 Token。价格估算不是实际账单；损坏的价格文件会导致金额隐藏。
6. 「低额度提醒」默认关闭；开启后，账户额度低于所选阈值时程序会尝试发送 Windows 通知。托盘菜单「提醒阈值」可选 10%、20%、30% 或 50%，默认 20%；通知显示取决于系统设置。「重置卡到期提醒」另有独立开关，默认关闭；已确认可用的 Codex 重置卡在 3 天内和 1 天内各提醒一次。
7. 「桌宠」默认隐藏，可选择「麻薯」或「比特」；单击可打开面板，拖动可调整位置。透明穿透和实际交互仍需实机验证。
8. 「第三方重置预测」默认关闭；开启后展示三个站点的数值、综合加权中位数、明确时间窗口和历史事件。色带是站点数值范围，不是置信区间；倒计时结束也不代表已经重置。预测不是个人账户额度的重置时间。账户页的周期倒计时仅使用账户服务给出的时间。
9. 「收集」页从可读取的本机逐日账本计算部分徽章，记录不完整或重复时结果可能有偏差；5 小时和 7 天额度达到阈值时会记录掉落卡片。额度窗口状态及卡片数量保存在 `%LOCALAPPDATA%\AgentMeter\collection.json`；其他徽章和卡片仍在移植。
10. 「设置 DeepSeek API 密钥」用于查询 API 账户余额，密钥保存在 Windows 凭据管理器，保存后启用查询；可在同一窗口删除密钥。该功能只经模拟测试，真实账户和窗口交互尚待验证。
11. 实验功能「登录 WorkBuddy」需要另行安装 Microsoft Edge WebView2 Runtime。登录资料保存在应用独立目录；取消不会清除，可用「清除本地登录」清除浏览数据，但不会在服务端退出。查询默认关闭，真实账户和部分登录方式尚未验证。
12. 对应账户额度和本机账本可读取时，Codex、Kimi、Claude、WorkBuddy 卡片会显示本机 Token 汇总及可用的近 30 个自然日趋势。本机记录未按账户区分，不等于账户额度或当前账户消耗；部分记录不完整时会提示。
13. 「应用」页按工具展示账户额度、本机用量和近 24 小时活动记录；点击应用名称可展开数据覆盖状态，顶部可筛选近期有更新的记录。页面可见时至少每 60 秒单独读取一次本机活动，隐藏面板或切换页面会取消当前读取；定时器交互仍需实机验收。记录更新不代表应用正在运行。

托盘图标里的数字是剩余百分比的整数近似值，悬停可查看来源、周期、采集和重置时间。在「托盘余量」中可选固定来源、最低余量或仅显示应用图标；选来源不会开启对应账户查询。自动模式比较有效窗口的百分比，不能用来比较不同服务的绝对额度。未知、超过 30 分钟的快照和已到重置时间的窗口不显示数字。

「本机消耗」页的「导出本机汇总」可保存 JSON 或 CSV，包含各可用账本的四个周期和 Token 拆分，不包括账户凭据、会话或路径。空字段表示未知而非零；账本可能重叠，导出内容也不是账户账单。CSV 使用带 BOM 的 UTF-8，方便 Windows Excel 打开。

「本机消耗」顶部可切换今日、近 7 天、近 30 天和累计；首屏汇总、各账本及可估算的 API 等价费用跟随切换。首屏费用只相加已知的美元估算，缺少来源时会提示，不能当作真实账单；本机账本可能重叠。趋势仍显示最近 7 个自然日，模型排行仍为近 7 天。周期保存在本机，下次打开时恢复。

「用量报告」保留本期截至当前日期和完整上期的总量，并单独对比两期前面相同数量的已结束自然日；当天不计入对照。上月天数较短时只比较共同天数，上期为零时不显示增幅。Markdown 报告包含此对照，分享图仍展示自然周期总量。

如需登录 Windows 后自动运行，可在托盘菜单开启「登录时启动」；默认关闭，启动后面板保持收起。设置只对当前 Windows 用户生效，Windows 启动应用设置仍可能阻止程序启动。移动程序前建议先在原位置关闭此选项，再从新位置开启；如旧项指向其他路径，程序会保护已有配置，可在注册表编辑器的当前用户 `Software\Microsoft\Windows\CurrentVersion\Run` 中检查 `AgentMeter.Windows` 条目。实体设备上的登录启动仍需验收。

「设置智谱 Coding Plan 密钥」用于查看智谱 GLM Coding Plan 额度，默认关闭；密钥由用户输入，保存在 Windows 凭据管理器，可在同一窗口删除。开启后经本地子进程标准输入传递，并通过 HTTPS 发往 `open.bigmodel.cn` 的用量接口，不读取浏览器或桌面登录。账号额度与本机 ZCode Token 账本分别统计；本功能目前仅经模拟测试，真实账户尚待验证。

「设置火山方舟 AccessKey」用于查看火山方舟 Coding Plan 额度，默认关闭。需要火山引擎访问控制中的 AccessKey ID 和 SecretAccessKey，并应使用仅有对应查询权限的凭据；模型调用 API 密钥不能用于此功能。两项凭据作为一条记录存入 Windows 凭据管理器，可在同一窗口删除。启用查询后经本地子进程标准输入传递，并签名请求 `open.volcengineapi.com` 的 `GetCodingPlanUsage`；不调用模型、不读取浏览器登录或环境变量。本功能目前仅经模拟测试，真实账户及权限尚待验证。

实验功能「登录小米 MiMo 平台」需要 WebView2 Runtime，默认关闭。用户在应用内独立窗口登录后，可查询平台余额和 Token Plan 月度额度；资料保存在 `%LOCALAPPDATA%\AgentMeter\webprofiles\mimo`，不会读取现有浏览器资料。「清除本地登录」清除应用内资料，不会在服务端退出。登录窗口只允许小米 MiMo 和小米账号相关 HTTPS 跳转，部分登录方式可能无法使用；真实登录和账户尚待验证。MiMo 平台账户与本机 MiMo Code 账本分别统计。

实验功能「登录 Qoder 中国区」需要 WebView2 Runtime，默认关闭。登录使用应用独立资料目录，不读取现有浏览器资料；清除本地登录不会在服务端退出。账户额度和本机积分消耗分别显示。登录主窗口及弹窗仅允许 Qoder 中国区 HTTPS 地址，部分登录方式可能无法使用；真实登录及账户尚未验收。

账户积分、Kimi 钱包及 Codex 重置卡现在收在对应账户卡片内。重置卡显示服务报告的总数和按到期顺序排列的明细，超过 3 条可展开；「已到期 · 待刷新」不会自行减少服务报告的总数。钱包与积分仍按各自单位展示，不能合并。

本机会话较多时首次扫描可能较慢。账户额度和本机 Token 分别统计；未提供的数据不会当作零。运行 `AgentMeter.Windows.exe --demo` 可查看虚构演示数据；运行 `AgentMeter.Windows.exe --window` 可用普通任务栏窗口查看真实数据。

Codex、Kimi、Claude 账户查询默认开启，MiniMax、DeepSeek、WorkBuddy、智谱、火山方舟、MiMo 和 Qoder 默认关闭；开关状态保存在 `%LOCALAPPDATA%\AgentMeter\preferences.json`，不包含凭据。Codex 额度查询使用本机已有的 Codex 安装和登录状态。如果 Claude Code 的本地订阅凭据文件存在，程序会在内存中读取访问令牌并通过 HTTPS 向 Anthropic 用量接口查询额度，不修改或刷新登录；该功能目前仅经模拟测试。Kimi 额度查询只连接已运行的本机 Kimi 服务，目前同样仅经模拟测试。

MiniMax 支持通过「管理 MiniMax 账户」添加最多 5 个账户，密钥保存在 Windows 凭据管理器，账户名称和区域保存在本机账户列表。主动开启查询后，密钥通过本地子进程标准输入传递，并通过 HTTPS 发往所选区域的 MiniMax 用量接口。账户列表文件不存在时，也可使用 `MINIMAX_TOKEN_PLAN_KEY` 与 `MINIMAX_REGION` 环境变量；通过界面清空账户后不会自动回退。关闭来源时程序会尝试中止当前账户查询，已发出的请求无法撤回。Windows 界面读取支持的本机历史，不通过该界面上传历史记录。详情见项目首页及 `THIRD_PARTY_NOTICES.md`；依赖许可文本位于 `licenses/`。
