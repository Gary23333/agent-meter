# Windows 版本

本目录包含 Windows 托盘界面、采集适配层、构建脚本和测试入口，代码来自 [FoxBai/agent-meter-windows](https://github.com/FoxBai/agent-meter-windows) 的移植分支，已合入本仓库主线。当前功能与原 macOS 版仍有差距；功能范围、使用方法和限制见[Windows 概览](OVERVIEW.md)（[English](OVERVIEW.en.md)），移植进度见[移植计划](PORT_PLAN.md)。

日常交互见[快速使用](QUICK_START.md)，弹层的尺寸、收起行为、时间口径和验证边界见[设计说明](DESIGN.md)，各版变化见[更新记录](CHANGELOG.md)。Windows 新代码、注释与文档以中文为主。

网络访问、凭据、本地缓存及清理行为见[隐私与本地数据](PRIVACY.md)。开发环境与提交约定见[参与贡献](CONTRIBUTING.md)，Windows 安全补充说明见[安全说明](SECURITY.md)。
